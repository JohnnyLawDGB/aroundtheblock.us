Products

HoldFast Wallet

Android · Non-custodial · Open source

A self-custody mobile wallet for DGB and DigiDollar on Android. Your keys are generated and stored on your phone, and sync runs on BIP157/158 compact block filters, so your addresses never leave your device. Formerly ATB Wallet. Coming to Google Play. An iOS version is in development.

Independent wallet by Around The Block LLC. Not an official DigiByte app.

Download and details → Source code

DigiScope

Explorer · Analytics · Education

A block explorer, on-chain analytics platform and education site for the DigiByte network. It includes exchange and network analytics. Trace addresses and transactions, browse DigiAssets, and learn how the chain works. Free to read, with no account required.

DigiScope is a hosted service, and DigiScope tip balances are held in a DigiScope-managed wallet, as described in our Terms.

Infrastructure

DigiByte network infrastructure

Part of the DigiByte community for more than eight years. Alongside the products, this work helps keep the network running.

  • Runs a seeder node for the DigiByte network.
  • Maintains a public Electrum endpoint for $DGB. Updated Electrum servers for DigiByte.
  • Built a Rosetta server implementation, in partnership with AI.
  • Independently built, verified and signed the DigiByte Core 8.22 release.
  • Tested the 9.26 release and contributed bug reports and fixes that shipped in the final version.
  • Takes part in the current DigiByte developer chats on Gitter.
  • Maintains and secures the price oracles that DigiDollar minting depends on.
  • Can trace stolen funds on-chain.
