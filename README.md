# aroundtheblock.us

Static website for Around The Block LLC, served with GitHub Pages.

- `index.html` / `home.html` – home page (`/` and the legacy `/home` path)
- `privacy-policy.html` – served at `/privacy-policy` (legal text copied verbatim from the previous site)
- `contact.html` – served at `/contact`
- `404.html` – not-found page

All internal links are relative so the site works both at the project-page preview URL and on the custom domain.
